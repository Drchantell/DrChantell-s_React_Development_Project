# Project Reflection

I built Dr. Chantell’s Country Explorer as my React cumulative assessment. This project helped me practice putting several React skills together in one application instead of working on only one small feature at a time. I used React with TypeScript, reusable components, state, Context API, a custom hook, controlled form fields, conditional rendering, and API data.

One of my biggest challenges was learning how to work with data coming from an API. At first, I had to understand the structure of the country information and decide which fields I needed. I also had to learn how to show a loading message, handle an error, and display the countries only after the data was ready. Breaking that work into a custom `useCountries` hook helped me understand the process better.

Another challenge was organizing the application into smaller components. As a beginner, it can be tempting for me to put everything in one file. I learned that separating the header, search controls, country cards, status messages, and country details made the project easier for me to read and understand.

I also worked through challenges with the light and dark theme, responsive CSS, search and region filters, and showing border countries on the detail view. I learned that I can solve larger problems by completing one small part at a time and testing my work as I go.

If I continue improving this project, I would like to add more country information, improve the animations, and continue practicing deployment. Overall, this project helped me become more comfortable using React and understanding how the different pieces of an application work together.
